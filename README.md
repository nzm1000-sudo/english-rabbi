# Smart English Tutor

מורה אישי לאנגלית לחמשת הילדים. פרטי, משפחתי, עובד במכשיר עצמו וגם בלי אינטרנט.

המערכת מכירה כל ילד בנפרד. היא מודדת רמה נפרדת לכל תחום (אוצר מילים, דקדוק, קריאה, כתיבה, האזנה, דיבור), לומדת מהטעויות, ובוחרת בכל רגע את התרגיל עם הערך הלימודי הגבוה ביותר.

## הפעלה

```bash
npm install
npm run dev        # פיתוח
npm test           # בדיקות
npm run build      # בנייה לתיקייה dist
```

התקנה באייפון: לפתוח את האתר ב־Safari, לבחור "שיתוף", ואז "הוספה למסך הבית". חשוב לעשות זאת. כך הנתונים לא נמחקים אוטומטית.

## איך זה עובד, בקצרה

1. **כל תשובה נשמרת כאירוע** ביומן שלא נמחק. כל השאר (רמות, חזרות, טעויות חוזרות) מחושב מהיומן ואפשר לחשב אותו מחדש בכל רגע.
2. **מפת מיומנויות.** לכל ילד ולכל מיומנות יש הערכת רמה וגם מידת ביטחון. אין ציון כולל אחד.
3. **מנוע אדפטיבי.** אחרי כל תשובה המערכת בוחרת את התרגיל הבא: חזרה שהגיע זמנה, מיומנות חלשה, טעות שחוזרת, ברמת קושי שמאפשרת הצלחה של כ־75%.
4. **חזרה מרווחת** לפי אלגוריתם `FSRS`.
5. **זיכרון לומד.** המערכת מזהה טעויות טיפוסיות, למשל בלבול בין `much` ל־`many`, ומחזקת אותן.
6. **לא נותנים תשובה מהר מדי.** רמז, רמז שני, הסבר, ורק אז התשובה.
7. **הקראה.** קולות טבעיים מוקלטים מראש, שרת ביתי בעתיד, וקול המכשיר כגיבוי.

פירוט טכני מלא: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
השוואת מנועי הקראה: [`docs/TTS-EVALUATION.md`](docs/TTS-EVALUATION.md).

## הוספת תוכן

מוסיפים קובץ `JSON` לתיקייה `content/packs`. המערכת בודקת כל פריט בטעינה. פריט ממקור שהרישיון שלו לא אושר ב־`content/sources.json` לא יוצג לילדים.

## פרטיות

כל הנתונים נשמרים במכשיר בלבד. אין שליחה לשירות חיצוני. אין חיבור לשירות בתשלום. גיבוי: מצב הורה, "גיבוי לקובץ".

## מצב נוכחי

שלב 1: תשתית, מנוע למידה, תוכן התחלתי (89 פריטים), מסכים בסיסיים, מצב הורה, מעבדת קולות. כתיבה חופשית, דיבור ושיחה עם מורה `AI` מתוכננים לשלבים הבאים.
