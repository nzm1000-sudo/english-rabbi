# English Rabbi

A responsive English-learning dashboard for Israeli 3-, 4- and 5-unit students. Choose a level for tailored grammar and vocabulary practice, get immediate answer feedback, and track study progress.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server, for example:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>. Your selected level and practice progress are saved in the browser when local storage is available.
